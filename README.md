# e-plantShopping

A React + Redux storefront for browsing and purchasing plants online. The app presents a landing page, product catalog organized into plant categories, and a cart experience with add, remove, and quantity-update actions.



## Overview

This project is a frontend-only ecommerce-style experience built with Vite and React. It does not include a backend, database, authentication, or API server. The plant catalog is defined directly in the frontend code, and the shopping cart is managed in Redux state.

The main user flow is:

- Landing page with brand messaging and About Us content
- “Get Started” button transitions to the plant catalog
- Product categories are displayed with plant cards and pricing
- Users can add products to the cart from the catalog
- Cart page allows quantity adjustments and item removal
- Continue shopping returns to the catalog
- Checkout button is present but currently shows a placeholder alert

## Features

- Responsive single-page storefront layout
- Product categories for:
  - Air Purifying Plants

  - Insect Repellent Plants
  - Medicinal Plants

- Redux-managed shopping cart

## Architecture and Component Interaction

The app’s runtime structure is straightforward and frontend-only:

- `src/main.jsx` mounts the React app and wraps it in `<Provider>` with the Redux store.
- `src/store.js` creates the Redux store with a single `cart` slice.
- `src/CartSlice.jsx` defines the cart state and actions:
  - `addItem`
  - `removeItem`
  - `updateQuantity`
- `src/App.jsx` is the top-level component. It renders the landing screen and toggles the product list view with `showProductList`.
- `src/ProductList.jsx` contains the plant catalog data, category rendering, cart toggle, and add-to-cart behavior.
- `src/CartItem.jsx` reads cart state from Redux and renders the cart item list, totals, quantity controls, and continue-shopping action.
- `src/AboutUs.jsx` renders the brand story and company description.

Important implementation notes:

- Plant data is embedded directly in `ProductList.jsx` as a JavaScript array.
- The cart state is kept in memory and is not persisted across browser refreshes.
- There is no backend or database layer in this repository.
- The checkout button currently triggers a browser alert placeholder message rather than a purchase flow.

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd e-plantShopping
npm install
```

## Configuration

This project does not use environment variables, `.env` files, or a backend configuration file.

There are no required API keys, no database configuration, and no authentication setup in the current codebase.

The only runtime configuration in the repository is the Vite base path in `vite.config.js`:

```js
export default defineConfig({
  base: "/shoppingreact",
  plugins: [react()],
})
```

This means the app is configured for a GitHub Pages-style path, and the `base` value may need to be adjusted if you deploy it to a different hosting path.

## Running the App

Start the development server:

```bash
npm run dev
```

This starts Vite in development mode. By default, the local app is available at the Vite development URL, typically:

```text
http://localhost:5173/
```

To preview the app more closely to production, you can run:

```bash
npm run build
npm run preview
```

The preview command is defined in `package.json` as:

```json
"preview": "vite build; vite preview --host"
```

Clicking the cart icon opens the cart view. In the cart, users can:

- increase quantity
- decrease quantity

## API and Backend Notes

This repository does not expose a REST API or GraphQL API.

There are no backend endpoints, no database models, and no remote service calls in the application. Product information and cart state are all handled client-side in React and Redux.

## Deployment

The project is set up as a static Vite app and includes `gh-pages` as a development dependency, which is commonly used for GitHub Pages deployment.

### Build for production

```bash
npm run build
```

This creates the production bundle in the `dist/` folder.

### Deploy to GitHub Pages

Because `vite.config.js` contains:

```js
base: "/shoppingreact"
```

the app is intended to be served under a site path. A typical static deployment workflow is:

```bash
npm run build
npx gh-pages -d dist
```

The repository also includes a live GitHub Pages link in the project metadata and the original README.
